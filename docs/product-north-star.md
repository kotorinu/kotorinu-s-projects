# Product north star

2026-09-17 scope expansion: the user's completion condition includes recurring
personalized RIALA DMs, daily community posts, event reminders seven and three
days before, and goal-linked execution with external readback. The current
application does not yet meet that condition. See [the completion audit](riala-autonomous-completion.md).

AI Work OS helps the operator decide what to do next. RIALA Planner narrows that goal to one loop: read the current RIALA state, prepare evidence-backed work, ask for the decisions only the operator must make, execute approved work, read the external result back, and record the next action.

The planner is intentionally small. It is one planner with WELCOME, EVENT, and CONTENT roles. It is not a collection of autonomous agents and it does not replace RIALA, Gmail, Notion, or the existing task and calendar surfaces.
