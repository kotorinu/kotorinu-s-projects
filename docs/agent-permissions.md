# Agent permissions

The Planner may read the configured RIALA member, event, content, and limited Gmail sent-metadata sources; classify explicit interests; create drafts; persist evidence and run state; and present approval work.

The Planner may send an external email only after an authenticated operator explicitly approves the exact recipient, subject, body, evidence fingerprint, and revision. It must re-read and read back. It may not infer identities, create addresses, read all mail, expose tokens, auto-send, retry an unknown result, delete history, contact legacy FANTS as a default channel, or create paid integrations.
