## 2026-09-30 カレンダーでPDCAを回す

- 従来の振り返りはアプリで「開始→完了」したTaskだけを集計していたが、計画はGoogle Calendarで立てておりTask操作はほぼ無いため、振り返りが空になりPDCAが回っていなかった。
- P=Calendarの予定、C=夜に○(できた)△(一部)×(できず)と理由を1つ、A=「明日ひとつ変えること」1行、に変更。アプリでTaskを作らなくても回る。
- 睡眠・休憩・予定なし・終日の予定は対象外。印を付けない予定は未記録で、できなかったとは数えない。△は半分で率を計算。記録時の予定名・時刻・色を写して残す（Calendarで後から消えても計画が分かる）。
- 記録は実績スナップショット `calendarReviews` として既存の版付き中央保存へ送る。サーバ側で日付キーと中身・結果・理由の形式を検証。
- TODAY: 昨日決めた改善を先頭に表示。18時以降は未記録の予定があれば「今日の予定を振り返る（3分）」を表示。振り返り画面の従来のTask実績は折りたたみへ移動。
- 検証: 実Google Calendar（9/29・9/30、15件）をブラウザに与え、9/29に○△×と理由・改善を記録→中央保存（模擬API、版2）→再読込で復元→TODAY先頭に表示→7日間集計まで確認。本番の実ログイン状態・実Redisでの読み戻しは未確認。
