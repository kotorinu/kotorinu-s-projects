# AI Work OS 現在地

更新: 2026-09-30

## 稼働しているもの

| 領域 | 状態 | 根拠 |
| --- | --- | --- |
| タスク・目標 | 中央保存、編集、競合停止、履歴に対応 | テスト群とWork API実装 |
| TODAY・計画 | Calendar読取、日次計画、実績記録、ICS書出しに対応 | 本番画面とテスト |
| AI実行 | キュー、lease、結果、証拠、レビュー状態を保存 | `lib/work/execution.ts`、Worker |
| 外部AI接続 | スコープ付きWork APIを実装 | `docs/work-api.md` |
| RIALA候補生成 | Welcome、7日前・3日前の副作用なし判定を実装 | `lib/riala-planner/recurring.ts` |
| RIALA実画面テスト | 2026-09-17〜23に投稿・イベント・DM・Learningを確認 | `operations/riala-test-runs/` |
| 営業支援 | 商談台本、質問集、保存履歴、練習UIを実装 | `app/sales-script` と関連テスト |
| UI改善 | TODAY、TASKS、GOALS、PDCA、各領域の階層と可読性を改善 | 2026-09後半のmain履歴 |

## 完成していないもの

| 優先度 | 未完了 | 完了の証拠 |
| --- | --- | --- |
| 高 | RIALAの安定した入力元と送信元 | 安定IDで会員・イベント・DMを取得し、許可された少数送信を外部で読み戻す |
| 高 | PC停止中も動くAI実行基盤 | スケジューラから実行し、成功・失敗・結果不明を中央保存できる |
| 高 | Chrome接続に依存する日次確認の復旧 | ログイン済みChromeで日次確認が再開し、Git運用記録へ反映される |
| 中 | 目標から仕事を自動発見する継続評価 | 目標との差、期限、重複、担当、証拠を定期評価してタスク化する |
| 中 | UIの実利用評価 | 主要フローを実データで使い、圧迫感・安心感・再利用意向を記録して改善する |
| 中 | PWA端末検証 | 実端末でインストール、再起動、オフライン表示を確認する |
| 低 | Calendar直接書込 | 最小権限の書込許可と読み戻しを確認する |

## 現在の運用制約

- RIALAはテスト期間。定期処理でDM送信、投稿公開、予約登録、プロフィール編集をしない。
- 外部送信は、対象、本文、根拠、最新状態を確定し、許可された範囲だけ実行する。
- 2026-09-24以降、Chrome接続が見えずRIALA実画面確認が停止している。Edgeを未確認の代替にはしない。
- APIや画面が存在するだけでは完成扱いにしない。外部結果の読み戻しまで必要。

より詳しい実装履歴は [completion-status.md](completion-status.md)、全体の不足は [whole-work-os-audit.md](whole-work-os-audit.md) を参照。
